# The probe subset scripts/check_corpus_parity.sh --subset re-derives, and the
# only parity evidence a pull request can afford to wait for.
#
# WHY A SUBSET. The whole sweep is ~32 min (docs/ci.md, "Nightly, not required
# on pull requests"), so it runs nightly and cannot hold a merge. This list is
# the fast half: it is judged against exactly the same byte oracle
# (scripts/corpus_parity_baseline.txt), so a probe in it that moves one byte
# fails a REQUIRED check on the pull request, while the nightly sweep keeps
# judging all 312.
#
# HOW IT WAS CHOSEN (mechanically re-derivable, R5 lane P3). Every probe's
# strategy.pine was scanned for the 40 engine mechanisms the corpus exercises
# at all -- order kinds, exit shapes, OCA, pyramiding, the three commission
# kinds, the three sizing bases, slippage, margin, the three calculation-timing
# switches, request.security / _lower_tf, the magnifier, sessions, calendars,
# timeframes, risk rules, ta/math/array/matrix/map/UDT/drawing surfaces -- and
# a greedy cover picked the fewest probes that witness all 40, preferring the
# probe with the larger trade surface on a tie. That is the first 14 rows. The
# cover was then topped up: one probe per corpus family of three or more
# members that the cover had missed, and the keepers below (the corpus's only
# anomaly-tier verdict, its largest two trade surfaces, and the mechanisms the
# campaign measured as divergence-prone: recompute state, risk rules, calendar
# and timeframe resolution, trade statistics).
#
# Every mechanism that exactly ONE probe in the whole corpus witnesses is in
# here by construction: strategy.cancel_all, calc_on_order_fills=true,
# commission.cash_per_order, a non-zero commission_value, and map.*.
#
# The subset is NOT a second oracle and has no baseline of its own: it names
# probes, and scripts/corpus_trades_identity.py --subset judges them against
# the same pinned sha256. Adding a row is free; removing one weakens the gate
# and needs the same evidence as moving the baseline.
#
# Format: one corpus-relative probe directory per line, '#' starts a comment.
