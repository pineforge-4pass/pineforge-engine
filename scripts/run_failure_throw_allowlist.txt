# Uncoded throws the run-failure throw scan accepts (scripts/check_run_failure_codes.py).
#
# The scan reads every throw statement -- `throw`, `std::throw_with_nested`,
# `std::rethrow_exception`, `std::rethrow_if_nested` -- in THROW_SCAN_GLOBS (the
# Pine-library headers generated strategies compile, the source layer, and the
# kernel units behind Pine built-ins). A throw there must either carry its code at its site
# (`throw coded<...>(RunFailureCode::..., {args}, "<English>")`, or a helper that
# does) or be admitted here. One row per kind of uncoded throw statement of a
# file:
#
#   path | throw text fragment | count | reason
#
# path      repo-relative, exactly as the scan prints it;
# fragment  a substring of the throw statement with its whitespace collapsed
#           (the first row of the path whose fragment matches wins, so identical
#           statements -- every `throw;` of one file -- share one row);
# count     how many throw statements of the path the row admits, exactly: the
#           scan fails on more (a new throw riding an old row) and on fewer;
# reason    why the site needs no code of its own: a rethrow (the exception in
#           flight keeps the code it carries, or the classifier's answer for
#           its type), or an engine invariant deliberately left to the
#           classifier's safety net (the std::logic_error family reads
#           engine_invariant). A strategy-reachable throw never belongs here.
#
# The check fails on an uncoded throw no row admits, on a row whose count is
# not the number of statements it matches, and on a row that matches no throw
# (stale). Blank lines and lines starting with `#` are ignored.
